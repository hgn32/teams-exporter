# Teams メッセージ抽出ツール

Teamsのメッセージ抽出ツールです。
処理は全て拡張機能内のJavaScriptで完結し、外部サーバーへの通信は一切行いません。

## できること

- Teams Web (`teams.microsoft.com`) のチャット・チャネル画面を自動スクロールしてメッセージを収集
  - 1:1・グループチャット
  - チャネル（投稿＋スレッド返信）
- 送信者名・日時・本文を1つのHTMLファイルとしてローカルにダウンロード（Downloads直下に `teams_export_<日時>.html`）
- 本文中の通常のリンク（外部URL等）はHTML出力でもクリックできるリンクとして復元
- 添付ファイル（SharePoint/OneDriveの共有リンク）は元のURLへのリンクとして表示（ダウンロードはしない）
- 画像は自動的にHTMLへbase64埋め込み（取得に失敗した場合のみ、元のURLへの通常リンクにフォールバック）

## できないこと

- 絵文字リアクションの収集
- 収集に10分以上かかる大データの書出

## インストール手順（開発者モードで読み込み）

### Chrome の場合

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. リポジトリをzipでダウンロード&解凍したフォルダ（`teams-extractor`）を選択

### Edge の場合

Edge は Chromium ベースで Manifest V3 拡張機能をそのまま読み込めるため、
本ツールもコード変更なしでインストールできます。

1. Edgeで `edge://extensions` を開く
2. 左側メニューの「拡張機能の管理」画面で「開発者モード」をON
   （左下または左側のトグルスイッチ）
3. 「展開して読み込み」（Load unpacked）をクリック
4. リポジトリをzipでダウンロード&解凍したフォルダ（`teams-extractor`）を選択

## 使い方

1. Teams Web で対象のチャット・チャネルを開く
2. 拡張機能アイコンをクリック
3. 「自動スクロール抽出を開始」をクリック
4. しばらく待つ（長いチャットほど時間がかかる。ポップアップは開いたままにする）
   - 新規メッセージが2周連続で拾えなくなった時点、または最大10分経過した時点で自動終了
   - 「抽出を中止」でいつでも打ち切り、その時点までの結果を取得可能
5. 完了すると、`Downloads/teams_export_<日時>.html` として保存される
   - 完了時のログに「画像: X/Y 件を埋め込み」等の診断情報が出る。画像が埋め込まれない場合はこのログを確認する

> **更新時の注意**: ソースを更新したら `chrome://extensions`（Edgeは `edge://extensions`）で必ず「再読み込み」すること。
> ポップアップに表示されるバージョンで、どの版が動いているか確認できる。

## ファイル構成

```
teams-extractor/
├── manifest.json   # 拡張機能の設定（MV3）
├── content.js      # Teamsページに注入し、DOM抽出・自動スクロールを行う
├── background.js   # 画像取得用service worker（host_permissionsで許可したホストの画像を取得）
├── popup.html      # ポップアップUI
└── popup.js        # ポップアップのロジック（HTML生成・ダウンロード）
```
