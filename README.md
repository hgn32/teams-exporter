# 社内用 Teams メッセージ抽出ツール（MVP / メッセージ本文のみ）

外部の Chrome拡張機能ストアのツールを使わず、社内で完結させるための自作版です。
処理は全て拡張機能内のJavaScriptで完結し、外部サーバーへの通信は一切行いません
（`host_permissions` は Teams のドメインのみで、`fetch`等のネットワーク呼び出しコードも含んでいません）。

## できること（このMVPのスコープ）

- Teams Web (`teams.microsoft.com` / `teams.live.com` / `teams.cloud.microsoft`) のチャット画面を
  自動スクロールしてメッセージを収集
- 送信者名・日時・本文をCSVまたはHTMLとしてローカルにダウンロード

## できないこと（今回のスコープ外）

- 添付ファイル・画像のダウンロード、ZIP化（次のステップで追加可能）
- 絵文字リアクションの収集
- チャネル（スレッド返信）への対応は未検証。1:1・グループチャットを主眼に作成

## 重要：セレクタは未検証です

このツールはTeams WebのDOM構造（`data-tid`属性やクラス名）に依存していますが、
**私（Claude）は実際にログイン済みのTeams画面を見て検証することができません**。
`content.js` 内のセレクタは、公開されている類似の OSS 拡張機能のコードを参考にした
「候補」であり、貴社のテナントで動く保証はありません。

そのため、以下の手順で必ず自分の環境で確認してください。

1. 拡張機能を読み込む（下記インストール手順）
2. Teams Web でチャットを開く
3. 拡張機能アイコンをクリックし「検出テスト」を押す
4. 「コンテナ検出: OK」かつ「現在表示中のメッセージ数」が0より大きければOK
5. 0件、またはNGの場合は、Teamsの画面上でメッセージ要素を右クリック→検証（Inspect）し、
   実際の `data-tid` やクラス名を確認して `content.js` 内の
   `SCROLL_CONTAINER_CANDIDATES` / `MESSAGE_ITEM_CANDIDATES` /
   `AUTHOR_SELECTOR_CANDIDATES` / `BODY_SELECTOR_CANDIDATES` に追記・修正してください

## インストール手順（開発者モードで読み込み）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`teams-extractor`）を選択

社内配布する場合は、Chrome Enterprise のポリシーで社内限定の拡張機能として
強制インストール設定にする方法もあります（詳細は別途）。

## 使い方

1. Teams Web で対象のチャットを開く
2. 拡張機能アイコンをクリック
3. 出力形式（CSV / HTML）を選んで「自動スクロール抽出を開始」をクリック
4. しばらく待つ（長いチャットほど時間がかかる。ポップアップは開いたままにする）
5. 完了すると自動的にファイルがダウンロードされる

## ファイル構成

```
teams-extractor/
├── manifest.json   # 拡張機能の設定（MV3）
├── content.js      # Teamsページに注入し、DOM抽出・自動スクロールを行う
├── popup.html       # ポップアップUI
└── popup.js         # ポップアップのロジック（CSV/HTML生成・ダウンロード）
```
