# ストア掲載用説明文

## 簡単な説明　※プレーンテキストであること

Microsoft Teams のチャット・チャネルの会話を自動スクロールで収集し、
Word(docx)・PDF・HTMLのいずれか1ファイルとしてローカルに保存するツール。外部サーバーへの送信は一切行わない。

---

## 詳細な説明　※プレーンテキストであること
Teams Web（teams.microsoft.com）で開いているチャット・チャネルの会話を、画面を自動スクロールしながら収集し、送信者名・日時・本文・画像・添付ファイルをWord(docx)・PDF・HTMLのいずれか1ファイルとしてダウンロードします。

【できること】
・1:1・グループチャット、チャネル（投稿＋スレッド返信）の両方に対応
・出力形式をWord (.docx)・PDF・HTMLから選択（既定はWord）
・送信者名・日時・本文を時系列順（Teams表示と同じ古い→新しい順）で出力
・本文中の通常のリンク（外部URL等）はどの形式でもクリックできるリンクとして復元
・添付ファイル（SharePoint/OneDrive等の共有リンク）は元のURLへのリンクとして表示（ダウンロードはしない）
・画像は自動的にファイルへ埋め込み（取得できない場合は元URLへの通常リンクにフォールバック）

【できないこと】
・絵文字リアクションの収集
・収集に10分以上かかる大量データの書き出し
・PDFでの絵文字の表示（「□」に置き換わります。絵文字を残したい場合はWordまたはHTMLを選択してください）

【プライバシーについて】
処理はすべて拡張機能内のJavaScriptで完結します。収集したメッセージや画像を外部サーバーへ送信することは一切ありません。通信が発生するのは、閲覧中のTeamsページに対して（利用者自身のログイン済みセッションで）画像を取得する場合のみで、送信先はMicrosoft Teams自体のドメインに限られます。
ソースコード: https://github.com/hgn32/teams-exporter

# Ko-fi連携メモ（ストア申請に貼れるもの/貼れないもの）

Chromeウェブストアの掲載ページはHTMLウィジェットを埋め込めない。
Ko-fiの各種ボタン/ウィジェットのうち、使えるのは以下のみ。

・ストア申請ページ → Ko-fiページのURLをテキストで書くだけ（上の【開発の支援】をコピペ）
・GitHubのREADME → 「GitHub tip button」(Markdown)が使える
・自分のWebサイト → Ko-fi button / tip widget（HTML埋め込み）
・QRコード → 印刷物・スライド用。ストアのスクリーンショット画像に混ぜるのは
  「機能デモでない画像」と審査で見なされるリスクがあるため非推奨
